## 一、十大高发类案

### 1. 刷单返利
- **套路**：以"做任务赚佣金"吸引 → 前期小额返利建立信任 → 诱导大额垫付 → 以"系统卡单/操作失误/缴保证金"为由要求继续充值 → 拉黑。
- **典型话术**：`先垫付`、`做满三单结`、`连本带利返你`、`卡单了要补单`、`保证金`。
- **识别点**：任何"先出钱、后返现"的组合。**前期真的会返钱**，这正是它最难识破的地方。
- **判定轴**：Take=money，Lever=benefit+urgency，Persona=recruiter/stranger。
- **变种**：色情小卡片引流、"约炮+做任务"、点赞关注返佣、快递引流进群。

### 2. 虚假网络投资理财
- **套路**：虚构"内部渠道/稳赚不赔" → 小额提现成功 → 加大投入 → 提现需缴"保证金/税费" → 平台跑路。
- **典型话术**：`内部消息`、`日化`、`稳赚`、`带你操作`、`先小额试试`、`提现要交20%保证金`。
- **识别点**：承诺收益 + 只让充不让提；提现永远差一步。
- **判定轴**：Take=money，Lever=benefit，Persona=synthetic/lover。

### 3. 虚假购物服务
- **套路**：低价商品/服务（二手数码、票务、代购）→ 要求脱离平台私下转账 → 收款后失联。
- **典型话术**：`平台收中介费，私下省200`、`先付定金`、`我人在外地只能快递`。
- **识别点**：**拒绝平台交易**本身就是最强信号。
- **判定轴**：Take=money，Lever=benefit+scarcity。

### 4. 冒充电商物流客服
- **套路**：谎称"商品质量问题/快递丢失"要理赔 → 引导提供银行卡号+验证码 → 或诱导下载会议软件共享屏幕。
- **典型话术**：`三倍赔付`、`系统校验`、`限时10分钟`、`下载这个会议软件我教你`、`开屏幕共享`。
- **识别点**：**任何索要验证码的"退款"都是诈骗**；屏幕共享=把验证码直接给对方看。
- **判定轴**：Take=money+info，Lever=urgency+authority。

### 5. 贷款与征信
- **套路**："您的贷款申请已通过" → 先缴会员费/保证金/刷流水 → 或以"注销校园贷/修复征信"为由要求转账。
- **典型话术**：`会员费激活额度`、`刷流水提升评级`、`不注销影响征信`、`提额需验资`。
- **识别点**：正规贷款**放款前绝不收费**；征信由央行统一管理，任何"修复征信"都是诈骗。
- **判定轴**：Take=money，Lever=fear+urgency。

### 6. 冒充领导熟人
- **套路**：盗号/仿号/AI 换脸拟声 → 以"急事借钱/帮我转账"为由要钱 → 强调"别告诉别人"。
- **典型话术**：`急用，先转我`、`不方便说`、`别跟我妈说`、`现在能视频吗（画质很卡）`。
- **识别点**：**换渠道验证是唯一解**——打电话、当面、问只有你们俩知道的细节。
- **判定轴**：Take=money，Persona=acquaintance，Lever=bond+urgency。

### 7. 冒充公检法
- **套路**：自称公安/检察院 → 称你涉嫌洗钱/涉案 → 要求"资金清查/转入安全账户" → 强调保密、不许挂电话。
- **典型话术**：`工号XXXX`、`涉嫌洗钱`、`安全账户`、`资金比对`、`不许告诉任何人`、`案件异地侦办`。
- **识别点**：**公检法没有"安全账户"**；真警察不会电话办案、不会让你转账、不会禁止你联系家人。
- **判定轴**：Take=money，Lever=fear+authority（最高危类型之一）。

### 8. 婚恋交友（杀猪盘）
- **套路**：精心人设（高管/工程师/博士）→ 每日嘘寒问暖建立情感 → 引导至"内部投资平台" → 小额尝甜头 → 加大投入 → 提现失败。
- **典型话术**：`我们俩的小秘密`、`内部渠道保密`、`我账户给你帮我看着`、`先交手续费解冻`。
- **识别点**：**感情升温 + 投资建议** 的组合；要求改用**小众聊天软件**；把账户交给你"代管"。
- **判定轴**：Take=money+affection，Persona=lover，Lever=bond+benefit。

### 9. 网络游戏产品虚假交易
- **套路**：买卖账号/装备 → 引导到"官方合作交易网站" → 假客服称"卡号填错账号冻结" → 缴解冻金。
- **典型话术**：`走XX交易网更安全`、`你卡号填错了`、`交1500解冻，交易完退回`。
- **识别点**：**任何非官方平台的"交易网站"**；任何以"账户冻结"为由让你充值的客服。
- **判定轴**：Take=money，Persona=peer/stranger。

### 10. 机票退改签
- **套路**：谎称航班取消/延误 → 主动"理赔" → 索要银行卡与验证码，或引导转账"验证账户"。
- **典型话术**：`航班取消`、`给您赔付`、`提供卡号和验证码`。
- **识别点**：退改签只走官方渠道；**赔付不需要验证码**。
- **判定轴**：Take=money+info，Lever=urgency。

## 二、20 个防诈关键词（公安部刑侦局）

> 每个词对应一种"作案装置"或"套路标记"。遇到这些词，风险等级应显著上调。

| # | 关键词 | 典型场景 | 识别要点 |
|---|---|---|---|
| 1 | **屏幕共享** | 冒充客服/公检法 | 诱导下载带屏幕共享的 App，直接看走验证码与账户信息 |
| 2 | **百万保障** | 冒充客服 | "误开通了百万保障，需要关闭"——该服务自动开通且免费 |
| 3 | **安全账户** | 冒充公检法 | 公检法**没有**安全账户，凡要求转入指定账户即诈骗 |
| 4 | **修复征信** | 贷款/征信 | 征信由央行征信中心统一管理，任何机构无权删除修改 |
| 5 | **刷单做任务** | 刷单 | 前期小额返利，大额转入后切断联系 |
| 6 | **色情小卡片** | 刷单变种 | 以色情服务为诱饵，导流至刷单/约会平台 |
| 7 | **未知链接、二维码** | 通用引流 | 可能导向恶意站点、木马或诈骗 App |
| 8 | **境外来电** | 通用引流 | 号码以 `+` 或 `00` 开头，多虚拟号；回拨常空号 |
| 9 | **小众聊天软件** | 杀猪盘/刷单 | 用户少、监管难，用于隐匿与销毁证据 |
| 10 | **内幕消息** | 虚假投资 | "独家情报、稳赚不赔、高额回报"即诈骗 |
| 11 | **NFC 盗刷** | 新型盗刷 | 要求手机贴靠银行卡，绑定虚拟 App 转移资金 |
| 12 | **积分清零** | 引流 | 假"积分清零"通知，点链接即入套 |
| 13 | **快递引流** | 引流 | 包裹内附传单/小礼品，扫码进群 |
| 14 | **虚拟货币** | 洗钱/投资 | 虚拟币交易不受法律保护，"兑换虚拟币投资"均为诈骗 |
| 15 | **电诈工具人** | 帮信 | 被诱骗帮取现、卖卡、推广引流的人 |
| 16 | **帮信行为** | 帮信 | 明知他人犯罪仍提供技术支持，可判三年以下 |
| 17 | **两卡** | 帮信 | 手机卡（含虚拟运营商、物联网卡）+ 银行卡（含支付账户） |
| 18 | **现金黄金** | 洗钱 | 要求取现/买金，再经跑腿、网约车、快递交付，逃避监管 |
| 19 | **购物卡** | 洗钱 | 要求大量购买购物卡并给卡号密码，用于套现 |
| 20 | **刷流水** | 贷款/洗钱 | 以"提升信用"为名诱导向指定账户转账 |

## 四、给 ChatGuard 的用法约束

1. **这份文件是"参照"，不是"判据"**。规则命中仍需与对话内容一致才采信（单一特征不定性）。
2. 关键词只能**上调风险**，不能单独定罪。例如出现"验证码"不等于诈骗——但"索要验证码 + 自称客服"就高度可疑。
3. 涉及**涉密/间谍**类（如以学术交流套取资料）不在本文件范围，见 `07` 的五轴体系与 `10` 的两级门槛。
4. 本文件不含任何真实姓名、号码、账号，可安全上传至知识库。
