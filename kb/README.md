# 知识库说明（ChatGuard KB）

## 这里面有什么

| 文件 | 内容 | 来源 |
|---|---|---|
| `01_类型与识别要点.md` | 十大高发类案 + **20 个防诈关键词** + 反诈利器 + 用法约束 | 公安部刑侦局/国家反诈中心《2025版宣传手册》；中国警察网《20 个防诈关键词》 |
| `02_校园与典型真实案例.md` | 2 个杀猪盘深度个案（含话术剧本结构）+ 4 个高校真实案例 | 央视/红网（澎湃转载）；乌审旗人民法院（澎湃转载） |

两份都是**公开信息的结构化改写**，不含真实姓名、号码、账号，可安全上传。

## 为什么只有这两份

按"知识库只放模型不知道 / 学校特有 / 会变的东西"这个原则筛过：

| 想放的内容 | 结论 |
|---|---|
| 通用诈骗话术科普 | ❌ 模型参数里已有，RAG 反而可能召回无关片段污染判断 |
| 可疑域名/文件名正则 | ❌ 该进代码规则（要精确率，白名单要硬逻辑） |
| 官方类型体系与关键词 | ✅ **模型知道大意，但不知道"官方口径"和最新变种** —— 有用 |
| 真实案例的结构与话术 | ✅ 给 `what_to_do` 提供具体参照，也让"假设并列"更有依据 |
| 本校处置流程/联系人 | ⏸ 暂缓（用户暂无信息），有了再加 `03_本校处置指南.md` |

## 怎么上传到平台

1. 平台 → 知识库 → 创建
2. 分段设置建议：**按标题分段**（我们文档是 `##`/`###` 结构，天然适合）
3. 索引：高质量（向量）+ 关键词
4. Top K：**3**（不要给太多，避免污染）
5. 相似度阈值：`0.5` 左右起步，实测再调
6. 在工作流「研判」节点前加一个**知识库检索**节点，把结果作为变量注入研判提示词

## 在工作流里怎么用（建议接法）

```
开始(chat_text) → 大模型·文本整理 → 代码·规则
                                    ↓
                    知识库检索（query = 规则里的 carriers + 类型候选）
                                    ↓
                    研判（提示词里加：参考知识库片段 {{#kb.result#}}）
                                    ↓
                                  回复
```

**关键**：检索 query 不要直接用整段聊天（太长、噪声大），用**规则层抽取的载体与类型候选**去检索，命中率更高。

## 提示词里的接法（研判节点加一段）

```
以下是从知识库检索到的官方口径与相似案例，仅供参考：
{{#knowledge.result#}}

使用要求：
1. 若对话特征与某个案例高度相似，可在 hypotheses 里引用该案例作为支持理由；
2. 知识库内容不能作为唯一定性依据，仍需对话本身存在索取动作；
3. 若检索结果与对话无关，忽略它，不要强行套用。
```
